# 🌐 Justus Putkonen – Portfolio

Tervetuloa portfoliooni!  
Tämä sivusto esittelee osaamistani, projektejani sekä taustaani ohjelmistokehittäjänä.  
Rakensin sivuston modernilla ja responsiivisella rakenteella, jotta se toimii sujuvasti kaikilla laitteilla.

---

## 🚀 Sisältö

Sivustolta löydät:

### 🏠 Etusivu
Lyhyt esittely siitä, kuka olen ja mitä teen.

### 💼 Projektit
Tänne kokoan omia projektejani, harjoitustöitä ja muita toteutuksia.  
(Projektit päivittyvät myöhemmin.)

### 🧠 Osaaminen
Listaus teknologioista ja työkaluista, joita hallitsen:

- JavaScript  
- HTML  
- CSS  
- PHP  
- SQL  
- API‑rajapinnat  
- Inkscape  
- Git  
- Visual Studio Code  
- Visual Studio  

### 📬 Ota yhteyttä
Sivustolla on yhteydenottolomake, jonka avulla voi lähettää viestin suoraan sähköpostiini.  
Lomake toimii EmailJS‑palvelun kautta.

---

## 🛠️ Käytetyt teknologiat

- **HTML5** – rakenteen toteutus  
- **CSS3** – ulkoasu ja responsiivisuus  
- **JavaScript** – lomakkeen toiminnallisuus ja interaktiivisuus  
- **EmailJS** – yhteydenottolomakkeen sähköpostien lähetys  
- **GitHub Pages** – sivuston julkaisu
